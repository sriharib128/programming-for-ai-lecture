Try it yourself

1

Measure the trade-off

Run vllm bench latency on a small model. Change the batch size. Plot latency and tokens per second.

2

Step through the engine

Set a breakpoint in llm.generate and follow one request through schedule and allocate_slots.

3

Hang a worker pool

Build a pool on one multiprocessing.Queue. Kill a worker with SIGKILL until the pool stops. Then fix it with one inbox per worker.

4

Survive a crash

Claim rows from a DB table with FOR UPDATE SKIP LOCKED. Kill a process mid-batch and check that nothing is lost.

If you want to take this further, here are four exercises, from easy to harder. The first needs a GPU and a small model. The second only needs patience with a debugger; the author of the walkthrough says that is the best way to learn this codebase, and we agree. The third and fourth need no GPU at all, and teach you the two failure lessons from Patram-Ingest in about a hundred lines of Python each. The third will hang intermittently, so you may have to run it many times, just as we did.
