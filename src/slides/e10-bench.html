Benchmarks

vLLM has a benchmark tool built in

vllm bench latency

A short input and 128 output tokens, in a small batch. Reports end-to-end latency.

vllm bench throughput

A fixed set of prompts, all at once. Reports tokens and requests per second.

vllm bench serve

Starts a server and sends requests with realistic arrival times. Measures every metric from the last slide.

vllm bench latency --model <model-name> --input-tokens 32 --output-tokens 128 --batch-size 8

An auto-tune script drives serve to find settings that meet a target, such as “maximize throughput with p99 end-to-end under 500 ms”.

Source: A. Gordić, Inside vLLM (2025)

You can measure all of this yourself, today, with no extra tools. The latency command uses a short input and small batch. The throughput command sends a fixed set of prompts at once. The serve command launches a server and simulates real traffic, with random gaps between requests. There is also an auto-tune script that searches for settings that meet a target you give it. A good exercise: run these on a small model and change one setting at a time.
