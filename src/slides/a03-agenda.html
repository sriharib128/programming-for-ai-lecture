Here is the plan for the next hour and a quarter. There are two halves.

The first half is vLLM. We start with why running a model for many people is hard at all. Then we go inside the engine and follow one small program through it. Then five features built on top of that core, and then how it grows from one GPU into a service you can call over the network.

The second half is Patram-Ingest, the system we built around vLLM to generate the training data you just saw. We explain what can interrupt a run that lasts for weeks, and then three problems in turn: keeping the GPUs busy, losing no work when machines die, and sending each page through many models on its own route.

At the end we put the two systems side by side and leave you with some exercises. Please interrupt us at any time; this works better as a conversation. A few slides will ask you for an answer, so stay ready. Let us start with the first part.
