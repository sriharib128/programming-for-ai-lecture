KV cache

Saving earlier work avoids repeating it

Without a cache

45 token computations for 6 new tokens

With a KV cache

10 token computations for the same 6 tokens
computed in this passread from the cache

The cost: the cache lives in GPU memory, and it grows with every token.

For each token, the model works out some numbers. The numbers for old tokens never change, so working them out again is a waste. On the left, nothing is saved: 45 computations for 6 new tokens.

So we save them, like taking notes instead of re-reading the book. Those numbers are called keys and values, so this is the KV cache. You do not need the details, only this: the same 6 tokens now take 10 computations. Keep the last line in mind. The cache lives in GPU memory, and it grows with every token. Most of what follows is about this one piece of memory.
